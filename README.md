# select-ui
Custom HTML Select 

## Purpose
Browsers do not allow native `<select>` options to be customized with modern styles. This lightweight library was created to give them a modern style.

## How to set it up?
1. Include the two required files:
    - `css/select-ui.css`
    - `js/select-ui.js`
2. Add the class `select-ui-class` to your HTML `<select>` tag. The script will automatically replace it with a modern style.

[View the source code in demo.html to see how to include the required files and use the library](demo.html)
